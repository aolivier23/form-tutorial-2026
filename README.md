# FORM Tutorial
A tutorial on how to use the phlex framework's I/O system.  Demonstrates registering a data product with FORM, writing data products from phlex, reading data products into phlex, how FORM handles phlex's data cell hierarchies, and eventually working with FORM files outside phlex.  This tutorial develops a handful of toy phlex algorithms to generate data products that FORM can read and write.
